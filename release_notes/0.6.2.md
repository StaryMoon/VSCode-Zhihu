# 0.6.2

这是 StaryMoon 维护版的回答发布增强版本。

## Big Update

- 新增 `Zhihu: Publish Markdown as Answer`：在 Markdown 编辑器中右键即可把当前文档发布为知乎回答。
- 如果 Markdown 首行没有 `#! https://www.zhihu.com/question/...`，插件会主动询问目标问题链接并自动写入。
- 在推荐、热榜、收藏的问题/回答条目上新增 `Zhihu: Write Answer for This Question`，可直接生成带目标问题链接的 Markdown 回答草稿。
- README 首页增加大字教程，明确区分“发布文章”和“发布回答”的操作路径。

## Notes

回答发布仍然复用原插件的知乎 Markdown 转换、图片上传、LaTeX、表格、Mermaid 转图和发布后回写链接能力。维护版 VSIX 继续保持原扩展标识 `niudai.vscode-zhihu`，安装后会覆盖升级原版插件。
