# 0.6.3

这是 StaryMoon 维护版的一个 UX 修正版本，重点把“阅读”和“写回答”拆开。

## 更新内容

- 推荐、热榜、收藏里的条目左键点击继续打开知乎阅读页，可以正常看问题和已有回答。
- `Zhihu: Write Answer for This Question` 改为右键菜单动作，需要写回答时对条目右键选择即可。
- 自动创建的回答草稿现在非常干净，只保留目标问题链接：

```markdown
#! https://www.zhihu.com/question/19602618
```

## 使用方式

1. 在 VSCode 左侧打开知乎插件并刷新推荐、热榜或收藏。
2. 左键点击条目用于阅读。
3. 右键条目，选择 `Zhihu: Write Answer for This Question`。
4. 在生成的 Markdown 文件里写回答。
5. 右键编辑器，选择 `Zhihu: Publish Markdown as Answer` 发布到该问题下。
