# 0.6.4

这是 StaryMoon 维护版的 Codex 阅读增强版本。

## 新增：导出问题和回答给 Codex

- `Zhihu: Export Question for Codex`
  - 粘贴知乎问题链接或问题 ID。
  - 选择要导出的回答数量，支持输入 `all` 导出全部回答。
  - 自动生成 `~/Downloads/zhihu-drafts/zhihu-question-<id>.md`。

- `Zhihu: Search Question for Codex`
  - 输入关键词搜索知乎问题。
  - 从搜索结果中选择一个问题。
  - 自动导出该问题和回答。

导出会复用插件已有的知乎登录态，但只写出问题、回答、作者、赞同数、评论数和正文内容，不会导出 cookie。

## 推荐工作流

1. 在命令面板运行 `Zhihu: Search Question for Codex`。
2. 输入你感兴趣的主题。
3. 选择问题并导出前 20 个回答。
4. 将生成的 Markdown 文件交给 Codex 做解释、风格分析或回答草稿。
