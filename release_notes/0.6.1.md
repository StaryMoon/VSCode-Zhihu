# 0.6.1

这是 StaryMoon 维护版的第一个小版本，基于上游 PR #211 的登录与收藏修复继续整理。

## Changes

- 恢复 `Zhihu: Preview` 命令，Markdown 文件可直接从编辑器标题栏或右键菜单预览知乎渲染效果。
- 新增明确的 `Zhihu: Publish Current Markdown` 命令，Markdown 文件可直接从编辑器标题栏、右键菜单或命令面板发布到知乎。
- 新增 `Zhihu: New Draft`，快速创建文章或回答草稿模板，回答模式支持自动写入 `#! https://...` 目标链接。
- 维护版 VSIX 保持原扩展标识 `niudai.vscode-zhihu`，安装后会升级原版插件，不会和原版同时注册同一批 `zhihu.*` 命令。

## Notes

如果你已经安装了原版 `niudai.vscode-zhihu`，可以直接安装此维护版 VSIX，它会作为 `0.6.1` 更新覆盖原插件。
